# Sample Data for IT Concepts

This directory contains JSON files with sample IT concepts, their relationships, and historical context.

## Files

- `concepts.json` - Collection of IT concepts with detailed information
- `layers.json` - Layer definitions based on network stack model
- `connections.json` - Relationship mappings between concepts

## Data Structure

Each concept includes:
- Basic information (name, description, category)
- Historical context (year created, creators, conditions)
- 3D position coordinates
- Connection references to other concepts

## Usage

These files are loaded by the application to populate the 3D visualization with initial data. You can modify these files to add new concepts or update existing ones.
